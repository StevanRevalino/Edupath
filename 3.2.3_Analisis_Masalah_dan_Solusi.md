# 3.2.3. Analisis Masalah dan Solusi

## Identifikasi Masalah

Berdasarkan hasil analisis data kuisioner lebih dari 100 responden dan wawancara dengan tiga narasumber profesional di bidang konseling, diperoleh beberapa permasalahan umum yang dihadapi siswa SMA dalam menentukan jurusan kuliah dan arah kariernya:

### 1. Kurangnya Pemahaman Diri (_Self-Awareness_) terhadap Minat dan Bakat

Sebanyak 51% responden menyatakan kesulitan karena tidak mengetahui minat dan bakat diri, dan hasil wawancara dengan para konselor juga menegaskan bahwa rendahnya kesadaran diri siswa menjadi hambatan utama dalam pemilihan jurusan.

Dampak: Hal ini menyebabkan banyak siswa memilih jurusan secara acak, ikut-ikutan teman, atau hanya berdasarkan opini orang tua tanpa mempertimbangkan potensi diri.

### 2. Keterbatasan Informasi Mendalam tentang Jurusan dan Prospek Karier

Sekitar 35,3% responden mengaku kesulitan karena minimnya informasi detail tentang jurusan dan 68,6% mengaku takut prospek kerja di masa depan kurang baik.

Sumber Informasi: Mayoritas siswa memperoleh informasi dari internet (69,6%) dan teman atau keluarga (49%), bukan dari sumber akademis yang terverifikasi seperti konselor sekolah atau _platform_ resmi universitas.

### 3. Pengaruh Eksternal dan Tekanan Sosial dari Orang Tua

Sebanyak 14,7% responden mengaku terpengaruh oleh tekanan keluarga dalam memilih jurusan. Para narasumber juga menyoroti bahwa komunikasi yang kurang terbuka antara siswa dan orang tua sering menyebabkan keputusan karier tidak sesuai dengan potensi anak.

### 4. Keterbatasan Akses Bimbingan Karier yang Terstruktur

Berdasarkan survei, 30,4% responden merasa kurang mendapatkan bimbingan, bahkan 2% mengaku tidak mendapatkannya sama sekali. Para narasumber menyampaikan bahwa proses bimbingan sering dilakukan secara manual dan terbatas, sehingga tidak semua siswa mendapat perhatian yang sama.

Penyebab: Keterbatasan waktu, sumber daya, dan kerja sama dengan pihak profesional.

## Solusi: Pengembangan Aplikasi EduPath

Berdasarkan identifikasi permasalahan tersebut, penulis mengusulkan pengembangan aplikasi berbasis _website_ (berdasarkan hasil kuesioner lebih dari 50% responden memilih _platform_ dalam bentuk _website_) bernama EduPath sebagai solusi digital yang dapat membantu siswa SMA dalam proses eksplorasi diri dan pengambilan keputusan jurusan kuliah.

## Fitur Utama EduPath

### 1. Tes Minat dan Bakat Berbasis RIASEC dengan _Fuzzy Logic_

Fitur ini dirancang untuk mengatasi Masalah 1 (Kurangnya _Self-Awareness_) dengan memberikan asesmen komprehensif menggunakan teori _Holland's RIASEC_ yang diintegrasikan dengan metode _Fuzzy Logic_.

#### 1.1. Konsep Dasar RIASEC

Tes menggunakan 6 tipe kepribadian _Holland_:

- R (_Realistic_) - Praktis, teknis, _hands-on_
- I (_Investigative_) - Analitis, peneliti, _problem-solver_
- A (_Artistic_) - Kreatif, ekspresif, inovatif
- S (_Social_) - Peduli, komunikatif, membantu orang lain
- E (_Enterprising_) - _Leadership_, persuasif, _entrepreneurial_
- C (_Conventional_) - Terorganisir, _detail-oriented_, sistematis

#### 1.2. Struktur Tes

- Jumlah Pertanyaan: 60 soal (10 pertanyaan per tipe kepribadian)
- Skala _Likert_: 1-5 (Sangat Tidak Setuju → Sangat Setuju)
- _Output_: Skor untuk setiap tipe (_Range_: 10-50)

#### 1.3. Implementasi _Fuzzy Logic_

Sistem menggunakan _Fuzzy Logic_ untuk menangani ambiguitas dan _overlap_ antar tipe kepribadian, karena dalam realitas tidak ada siswa yang memiliki tipe kepribadian 100% tunggal.

##### A. Rumus Fuzzifikasi (_Triangular Membership Function_)

Setiap skor RIASEC dikonversi menjadi nilai keanggotaan _fuzzy_ menggunakan fungsi keanggotaan segitiga:

**1. _Membership Function_ untuk LOW (10-30)**

```
μ_LOW(x) = {
  1,              jika x ≤ 20
  (30-x)/10,      jika 20 < x < 30
  0,              jika x ≥ 30
}
```

**2. _Membership Function_ untuk MEDIUM (25-40)**

```
μ_MEDIUM(x) = {
  0,              jika x < 25
  (x-25)/7.5,     jika 25 ≤ x ≤ 32.5
  (40-x)/7.5,     jika 32.5 < x < 40
  0,              jika x ≥ 40
}
```

**3. _Membership Function_ untuk HIGH (38-50)**

```
μ_HIGH(x) = {
  0,              jika x < 38
  (x-38)/4,       jika 38 ≤ x ≤ 42
  1,              jika x > 42
}
```

Parameter _Membership Functions_:

| Kategori | _Range_ Skor | _Peak_ (μ=1) | Batas Naik    | Batas Turun   |
| -------- | ------------ | ------------ | ------------- | ------------- |
| LOW      | 10-30        | x ≤ 20       | -             | 20 < x < 30   |
| MEDIUM   | 25-40        | x = 32.5     | 25 ≤ x ≤ 32.5 | 32.5 < x < 40 |
| HIGH     | 38-50        | x > 42       | 38 ≤ x ≤ 42   | -             |

Contoh Perhitungan:

Jika siswa mendapat skor _Investigative_ = 38:

```
μ_LOW(38) = 0 (karena 38 ≥ 30)

μ_MEDIUM(38) = (40-38)/7.5 = 2/7.5 = 0.267 (descending part)

μ_HIGH(38) = (38-38)/4 = 0/4 = 0.0 (ascending part, tepat di batas)

Hasil: Investigative = {LOW: 0.0, MEDIUM: 0.267, HIGH: 0.0}
```

##### B. _Fuzzy Rule Base_ dan _Inference Engine_

Sistem menggunakan **Metode Tsukamoto** dengan 9 _fuzzy rules_ berdasarkan kombinasi _Primary_ dan _Secondary Type_.

Struktur _Fuzzy Rule_:

```
IF [Primary_Type = FUZZY_LEVEL_1] AND [Secondary_Type = FUZZY_LEVEL_2]
THEN Consequent = LINGUISTIC_OUTPUT
```

**9 _Fuzzy Rules_:**

| No  | _Primary_ | _Secondary_ | _Consequent_ | _Range Output_ (%) |
| --- | --------- | ----------- | ------------ | ------------------ |
| 1   | HIGH      | HIGH        | VERY_HIGH    | 90-100             |
| 2   | HIGH      | MEDIUM      | HIGH         | 75-90              |
| 3   | MEDIUM    | HIGH        | HIGH         | 75-90              |
| 4   | HIGH      | LOW         | MEDIUM       | 60-75              |
| 5   | MEDIUM    | MEDIUM      | MEDIUM       | 60-75              |
| 6   | LOW       | HIGH        | LOW          | 40-60              |
| 7   | MEDIUM    | LOW         | LOW          | 40-60              |
| 8   | LOW       | MEDIUM      | LOW          | 40-60              |
| 9   | LOW       | LOW         | VERY_LOW     | 20-40              |

**Mekanisme _Inference_:**

Untuk setiap _rule_, sistem menghitung **firing strength** (α) menggunakan operator MIN:

```
α = MIN(μ_primary, μ_secondary)
```

Contoh: Jika Primary=HIGH dengan μ=0.8 dan Secondary=MEDIUM dengan μ=0.6, maka:

```
α = MIN(0.8, 0.6) = 0.6
```

##### C. Defuzzifikasi Metode Tsukamoto

Untuk setiap _rule_ yang _fired_ (α > 0), sistem menghitung nilai _crisp output_ (z) berdasarkan _consequent_:

**Formula Defuzzifikasi Tsukamoto:**

```
z = output_min + α × (output_max - output_min)
```

**Tabel _Consequent Output_:**

| _Consequent_ | _Range_ (%) | Formula         | Contoh (α=0.6)   |
| ------------ | ----------- | --------------- | ---------------- |
| VERY_LOW     | 20-40       | z = 20 + α × 20 | z = 20 + 12 = 32 |
| LOW          | 40-60       | z = 40 + α × 20 | z = 40 + 12 = 52 |
| MEDIUM       | 60-75       | z = 60 + α × 15 | z = 60 + 9 = 69  |
| HIGH         | 75-90       | z = 75 + α × 15 | z = 75 + 9 = 84  |
| VERY_HIGH    | 90-100      | z = 90 + α × 10 | z = 90 + 6 = 96  |

##### D. _Weighted Average_ untuk _Final Output_

Setelah semua _rules_ dievaluasi, sistem menghitung _match percentage_ final menggunakan _weighted average_:

```
Match_Percentage = Σ(αᵢ × zᵢ) / Σ(αᵢ)

Dimana:
αᵢ = firing strength dari rule ke-i
zᵢ = crisp output dari rule ke-i
```

**Contoh Perhitungan:**

Misalkan 3 _rules fired_:

- Rule 1: α₁ = 0.8, z₁ = 95 → Kontribusi = 0.8 × 95 = 76
- Rule 2: α₂ = 0.6, z₂ = 84 → Kontribusi = 0.6 × 84 = 50.4
- Rule 3: α₃ = 0.2, z₃ = 69 → Kontribusi = 0.2 × 69 = 13.8

```
Match% = (76 + 50.4 + 13.8) / (0.8 + 0.6 + 0.2)
       = 140.2 / 1.6
       = 87.625%
       ≈ 88% (dibulatkan)
```

_Threshold_ Kategori Hasil:

| _Match Percentage_ | Kategori     | Interpretasi                                    |
| ------------------ | ------------ | ----------------------------------------------- |
| ≥ 85%              | Sangat Cocok | Rekomendasi utama, potensi sukses sangat tinggi |
| 75-84%             | Sangat Baik  | Sangat direkomendasikan                         |
| 65-74%             | Baik         | Cocok, pertimbangan kuat                        |
| 55-64%             | Cukup        | Dapat dipertimbangkan dengan analisis lanjutan  |
| < 55%              | Kurang Cocok | Tidak direkomendasikan                          |

##### E. Contoh Kasus Perhitungan Lengkap

_Input_ Data Siswa:

```
Nama: Ahmad
Skor RIASEC:
- Realistic (R): 45
- Investigative (I): 42
- Artistic (A): 18
- Social (S): 20
- Enterprising (E): 22
- Conventional (C): 28
```

_Step_ 1: Fuzzifikasi

```javascript
// R = 45 (x > 42, jadi HIGH = 1)
R = 45: {LOW: 0.0, MEDIUM: 0.0, HIGH: 1.0}

// I = 42 (x = 42, jadi HIGH = (42-38)/4 = 1.0)
I = 42: {LOW: 0.0, MEDIUM: 0.0, HIGH: 1.0}

// A = 18 (x ≤ 20, jadi LOW = 1)
A = 18: {LOW: 1.0, MEDIUM: 0.0, HIGH: 0.0}

// S = 20 (x = 20, jadi LOW = 1)
S = 20: {LOW: 1.0, MEDIUM: 0.0, HIGH: 0.0}

// E = 22 (LOW = (30-22)/10 = 0.8, tidak masuk MEDIUM karena < 25)
E = 22: {LOW: 0.8, MEDIUM: 0.0, HIGH: 0.0}

// C = 28 (LOW = (30-28)/10 = 0.2, MEDIUM = (28-25)/7.5 = 0.4)
C = 28: {LOW: 0.2, MEDIUM: 0.4, HIGH: 0.0}
```

_Step_ 2: _Inference Engine_ - Evaluasi _Fuzzy Rules_

Teknik Elektro membutuhkan: _Primary_=R, _Secondary_=I

```javascript
// Evaluasi 9 fuzzy rules dengan Primary=R dan Secondary=I

// Rule 1: IF R=HIGH AND I=HIGH THEN VERY_HIGH
α₁ = MIN(μ_R(HIGH), μ_I(HIGH)) = MIN(1.0, 1.0) = 1.0
z₁ = 90 + (1.0 × 10) = 100
Kontribusi₁ = 1.0 × 100 = 100

// Rule 2: IF R=HIGH AND I=MEDIUM THEN HIGH
α₂ = MIN(μ_R(HIGH), μ_I(MEDIUM)) = MIN(1.0, 0.0) = 0.0
(Rule tidak fired karena α = 0)

// Rule 3: IF R=MEDIUM AND I=HIGH THEN HIGH
α₃ = MIN(μ_R(MEDIUM), μ_I(HIGH)) = MIN(0.0, 1.0) = 0.0
(Rule tidak fired)

// ... Rules 4-9 juga tidak fired karena salah satu antecedent = 0

// Hanya Rule 1 yang fired
```

_Step_ 3: _Weighted Average_

```javascript
Match% = Σ(αᵢ × zᵢ) / Σ(αᵢ)
       = (1.0 × 100) / (1.0)
       = 100%

Match_Percentage = 100% → "Sangat Cocok"
```

**Catatan:** Karena Ahmad memiliki R=45 (HIGH=1.0) dan I=42 (HIGH=1.0), maka hanya Rule 1 (HIGH+HIGH→VERY*HIGH) yang \_fired* dengan α=1.0, menghasilkan _match_ sempurna 100%.

Hasil Rekomendasi _Top_ 5 untuk Ahmad:

1. Teknik Elektro - 100% (Sangat Cocok)
2. Teknik Mesin - 100% (Sangat Cocok)
3. Teknik Informatika - 100% (Sangat Cocok)
4. Fisika - 100% (Sangat Cocok)
5. Kimia - 100% (Sangat Cocok)

**Penjelasan:** Ahmad memiliki profil R=HIGH dan I=HIGH yang sangat kuat, sehingga semua jurusan STEM dengan requirement R-I atau I-R mendapat _match_ sempurna karena _rule_ "HIGH+HIGH→VERY_HIGH" menghasilkan output 90-100%.

#### 3.1. Sistem Penjadwalan Konsultasi

| ----------------------- | ---------------------------------------------- |

| _Reminder Notification_ | Notifikasi H-1 dan 1 jam sebelum konsultasi    |

- _Real-time messaging_ antara siswa dan konselor

- _Chat history_ untuk _review_ percakapan sebelumnya
- _Time-based access_ - _Chat_ hanya aktif saat jadwal konsultasi

#### 3.3. _Pre-Consultation Data Sharing_

Konselor mendapat akses ke:

- Hasil tes RIASEC siswa

Dengan data ini, konselor dapat:

- Memberikan analisis lebih mendalam

- Memfasilitasi diskusi dengan orang tua

         ↓  (z berdasarkan consequent: VERY_LOW, LOW, MEDIUM, HIGH, VERY_HIGH)
         ↓
[WEIGHTED AVERAGE: Match% = Σ(α×z) / Σ(α)]
         ↓
[Ranking & Threshold Kategorisasi (0-100%)]
         ↓
